Što vidite u demu

Stvarni scenarij. Tri perspektive.

Demo prikazuje logističku tvrtku s 12 vozača — isti scenarij opisan u case studyju. Svaka uloga ima drugačiji prikaz i drugačije ovlasti.

📋
MIRNA
Dispečerica — puni pristup
  • Kreira novi nalog za 90 sekundi
  • Dodjeljuje vozaču iz padajućeg izbornika
  • Vidi status svih naloga u realnom vremenu
  • Označava hitne naloge
  • Generira dnevni izvještaj jednim klikom
🚚
MARKO
Vozač — mobilni prikaz
  • Vidi samo svoje naloge
  • Potvrđuje preuzimanje jednim klikom
  • Ažurira status: krenuo / završio
  • Optimizirano za mali ekran mobitela
  • Radi i s lošim signalom
👁️
TOMISLAV
Vlasnik — pregled bez izmjena
  • Dashboard svih vozača i naloga
  • Vidi tko je gdje u realnom vremenu
  • Statistike za tekući dan
  • Nema gumba — samo čita
  • Otvori na mobitelu, laptopu, bilo čemu
Što je unutra

Jedna datoteka. Sve u njoj.

Nema ovisnosti koje trebate instalirati. Nema Pythona, nema Node.js, nema ničega — sve je zapakrano unutar jedne izvršne datoteke.

⚙️
Python + FastAPI
Lokalni web server koji pokreće svu logiku. Identičan stack koji koristimo u stvarnim projektima za klijente.
🗄️
SQLite baza podataka
Lokalna baza koja se kreira automatski pri prvom pokretanju. Sve se sprema lokalno — nema podataka koji odlaze negdje.
🔄
Real-time sinkronizacija
Promjena u jednom tabu odmah se vidi u svima. Server šalje ažuriranja svim otvorenim browserima automatski.
🔁
Automatski reset
Demo se vraća na početno stanje svakih 60 minuta. Uvijek čist za sljedeću demonstraciju.

Ovo nije demo — ovo je stvarni softver

  • Isti tehnološki stack kao aplikacija koju bismo razvili za vas
  • Podaci ostaju na vašem računalu — ne idu nigdje
  • Radi bez interneta, bez cloud servisa, bez pretplate
  • Možete ga pokrenuti na USB sticku, na mreži, na bilo čemu
  • Vaša prilagođena verzija bila bi krojena točno po vašim procesima

Vidite potencijal za vaše poslovanje?

Demo prikazuje logistiku — ali isti pristup primjenjujemo na HVAC servise, građevinu, distribuciju i sve gdje postoje terenske ekipe i uredska koordinacija.
